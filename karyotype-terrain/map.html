Music's Karyotype

the genome as terrain — chromosome territories as peaks
hover to read the terrain
valley — sparse territory
foothills — transition zone
slopes — genre boundary
ridge — high chromosome density
peak — genre centre
Each peak is a chromosome territory — a genre. Height = chromosome density (how many songs cluster here). Ridges between peaks = lineage paths (evolutionary routes along which genetic material flowed). Valleys = transition zones where genre boundaries gradient into each other. The terrain is continuous. No walls. Only crossfades.
